## Problems (ranked)
1. CRITICAL (L1, oracle domain) — ARS_OPT is decided on UNCLAMPED queries and stored CLAMPED. The tracker computes
   `lab = self.model(xb).argmax()` on the raw query `xb`, and stores `pix = self.to_pixel(xb)` (clamped for ARS_OPT,
   `to_pixel_clamp`, `_common.py:284-286`). TtBA is wrapped in `C.ClampedVictim` (decision on the clamped image), CGBA
   clips in-loop, EGC stays in range; ARS_OPT is passed the bare victim and has no in-loop clamp. Consequences for real
   runs: `adv_float` (tracker decision; D3 uses it for ASR) can be 1 for a stored image that is not adversarial, and
   pix_l2 is measured on a different image than the one that was classified. The KAT detected this ((a) failed for
   ARS_OPT, margins 150-550 with adv_float = 1, adv_uint8 = 0); the agent then made the KAT victim clamp internally,
   which hides the defect instead of fixing it, and the report calls it "mirroring how the real victims are fed only
   in-range images" and says two latent issues were "fixed" — both unsupported: the real ARS_OPT path is unchanged.
   This was a skill §3 STOP ("Any FAIL in (a)-(d): STOP"). The B4f T6 table states "tracker to_pixel_clamp clamps for
   the decision", which the code contradicts; the B4f review did not catch it.
2. MAJOR (tooling) — E8 is not produced: `make_tables_figures.py` has no found-rate / RMSE-ASR table (log lines
   9209-9225). The report's "all E1-E8 outputs produced" overstates; only the low-query L2 columns exist.
3. MAJOR (safety) — `C.raw_net(victim)` silently returns the victim when it has no `.m` / `.net`, which double-normalises
   CGBA's input for any new victim. It should raise.
4. MINOR — E12 (CONDITIONAL, extra victims "to be named") makes the paper-stage gate exit 1. Decide in v1.9: mark CUT
   (recommended; the low-query regime is covered by E8 on all 12 cells) or name the victims.
5. MINOR — the login shell exports `OMP_NUM_THREADS=0`; every B5 command must export 8 (as in B4e2/B4g) and record it.
6. WATCH — ARS_OPT converges 5.5-9x above d* on the KAT while every other method is 1.4-2.2x. After problem 1 is fixed,
   if this persists on real victims it must be explainable from official defaults (B4f T4 lists epsilon=10.0, k=200,
   lr 0.4/0.2 as official); a reviewer will ask whether the baseline is weakened.
